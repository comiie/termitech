# 晨昏线官网

基于 Figma 首页节点 `289:2` 的官网实现，案例按 `290:550`、`290:558`、`290:539`、`290:566` 四张画板的顺序展示。

## 本地运行

```bash
npm install
npm run dev
```

## 实现约定

- 设计基准为 1920 × 8116，1080px 对应设计稿一屏。
- 页面随视口宽度等比适配，1920 × 1080 下与设计稿 1:1 对齐。
- 桌面端保留产品横向滚动、闭环切换和案例滚动叠图动效；案例分两组，每组两个小点，前两张文案在左侧，后两张在右侧。
- 1024px 及以下使用平铺布局，四个案例全部展开并隐藏小点；桌面保留分组叠卡切换。
- 案例图片悬停或键盘聚焦显示“了解更多”，无悬停能力的触屏设备直接显示按钮。
- 位图素材使用高质量 WebP，视频使用 WebM；社媒图标保持 SVG。
- Banner 视频在 HTML 中提前发现并加载，页面脚本保留同一个视频元素；下方图片延迟加载，避免争抢首屏带宽。
- WebM 保留原始 VP9 / Opus 音视频流，仅将索引前置并缩短媒体簇（500ms / 256KiB），不重新编码。更换视频内容时同步更新 HTML 中的资源版本参数。
- 原生滚动位置保留，右侧滚动条隐藏；键盘、触控板和触摸滚动均可用。
